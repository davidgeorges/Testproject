# Décision de nom : Clarysio

**Décision du 11 septembre 2026 :** le nom commercial visible de l’application devient **Clarysio**.

Le nom associe la clarté à l’organisation. Il couvre le périmètre réel du produit : budget, abonnements, documents, échéances et foyer, sans réduire l’application à une banque.

## Contrôles préliminaires

- recherche exacte du nom sur le Web, l’App Store et Google Play : aucune application mobile homonyme identifiée ;
- RDAP `clarysio.com` et `clarysio.fr` : réponse `404` au moment du contrôle, ce qui indique qu’aucun enregistrement RDAP actif n’a été trouvé ;
- une occurrence commerciale sans rapport avec le logiciel existe pour un modèle de luminaire.

Ces contrôles sont préliminaires. Avant publication publique, il reste à commander une recherche d’antériorité INPI/EUIPO, réserver les domaines et déposer la marque si elle est retenue juridiquement.

## Identifiants techniques conservés

Les valeurs suivantes restent volontairement inchangées :

- projet Expo : `@azetoxvii/subscription-project` ;
- schéma de lien : `subscriptionapp://` ;
- bundle iOS et package Android : `com.davidgeorges.subscriptionapp` ;
- espaces de noms .NET : `SubscriptionApp`.

Ces identifiants sont invisibles dans l’interface et sont déjà liés à Firebase, Google OAuth, Tink, EAS et Render. Les modifier maintenant invaliderait les redirections et identifiants signés. Le nom visible, l’icône et le splash utilisent Clarysio dès maintenant.
